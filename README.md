# Enterprise Agentic AI & Intelligent Automation Platform

## Project Overview

An enterprise-level AI-powered platform designed to automate business workflows, manage operations, and provide intelligent assistance using Agentic AI technologies.

## Technologies Used

- Python
- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication
- Pydantic
- Pytest
- Git & GitHub

## Current Features

- User Registration
- Secure Password Hashing
- User Login
- JWT Access Token Authentication
- Protected User Profile API
- Database Integration
- Automated Authentication Tests
